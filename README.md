### What I work on

I work on two sides of the same problem: the software that produces data, and the infrastructure that turns it into something a business can act on.

**Building systems.** REST APIs and backend services in Python and Java, layered architectures with authentication and role-based access control, containerized deployments, and client-server applications where the interesting part is the contract between the pieces.

**Building the data layer underneath.** ETL/ELT pipelines on cloud infrastructure, warehouse modeling on BigQuery, and the reporting surface on top of it.

My day-to-day runs in a regulated industry, which means traceability, data quality and documentation are requirements rather than afterthoughts. That has shaped how I build: explicit contracts, reproducible processes, and systems someone else can pick up without me in the room.

**[Vecindario Amigo](https://github.com/Juan-David-Obando-Novoa/Vecindario-amigo.git)** — `Java` `Spring Boot` `Angular` `PostgreSQL`
Full-stack community platform on a layered architecture. Authentication, role-based permissions, and security controls governing what profile data each role can see and share.

**[BudgetBuddy](https://github.com/Moviles-G45)** — `Kotlin` `FastAPI` `Docker` `BigQuery`
Personal finance mobile app on a client–server architecture: containerized cloud backend, access management, and an ETL pipeline feeding transaction analytics into BigQuery.

**[UNFPA Text Analytics Platform](https://github.com/Juan-David-Obando-Novoa/Proyecto1BI.git)** — `Python` `FastAPI` `React` `scikit-learn`
Classification service mapping citizen opinions to the UN Sustainable Development Goals. Naive Bayes + TF-IDF model exposed through a REST API, with an incremental retraining flow so the model can be updated without redeploying the service.
